# Guransh's Portfolio

A professional React portfolio for a software developer / data analyst / ML engineer, built with Vite.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
```

Output in `dist/`.

## Deploy on Vercel

1. Push to GitHub
2. Import the repo at [vercel.com](https://vercel.com)
3. Vercel auto-detects Vite — click **Deploy**

Or via CLI: `npx vercel`
