# Ask-first portfolio

Personal site shaped like an AI chat app: visitors ask, and the site answers with grounded text, project demos, roles and music. The build plan is in [PHASES.md](PHASES.md).

```bash
npm install
cp .env.example .env.local   # fill in keys
npm run dev
npm run typecheck
npm run lint
npm test
```

Open [http://localhost:3000](http://localhost:3000).
